# Frontlines Warfare

A 3D war shooter that runs in the browser — everything is in `index.html`.

**Play:** open the deployed site, or open `index.html` in a browser.

**Deploy on Vercel:** import this repo at vercel.com/new (Framework preset: Other, no build command). Every push to `main` redeploys.

Online battles and game codes use the Ares Revision Supabase project (Realtime + `game_codes` table).
